## 🧩 About

**Minecraft Helper** is a comprehensive utility mod for Minecraft Java Edition featuring coordinate overlay, auto-farm, entity radar, fullbright, inventory manager, and fast-place.

Based on popular mods like **OptiFine**, **Sodium**, and **JourneyMap**.

---

## ✨ Features

### 🎮 Core Helpers
- Coordinate Overlay — display real-time coordinates on screen
- Auto-Farm — automatically harvest and replant crops
- Entity Radar — show nearby entities and players
- Fullbright — remove darkness and see in caves
- Fast Place — place blocks rapidly

### 🎨 Visuals & UI
- Custom HUD — configure on-screen information panels
- Chest ESP — highlight nearby chests and containers
- Waypoints — set and navigate to custom waypoints

### 🏋️ Utility & Automation
- Inventory Manager — auto-sort and organize items
- Auto-Tool — switch to the best tool for the job
- Fast Sneak — toggle sneak without holding the key
- Anti-AFK — prevent being kicked for inactivity
